# Gwendolyn Direct v0.46.11-alpha1

This maintenance alpha brings the public application up to the current conducted-session line.

- Waits for Signal Lab live readback when establishing a conducted-session baseline.
- Encourages deliberate exploration across the active carrier/texture preset rather than repeatedly returning both lanes to the starting frequency.
- Verifies Vector targeting and stroke-range modifier results against controller-owned state.
- Uses direct grounded confirmation for exact targeting and modifier actions.
- Clarifies that targeting does not silently change the selected bottom focus.
- Removes malformed model channel markers before display and again before speech.
- Retains curated Vector event support, heart-tempo modes and ReStim sensor auto-reconnect.

Personal profiles, vocabulary, memories, logs, model files, session reports and voice recordings are not included.
