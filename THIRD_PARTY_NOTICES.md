# Third-party software

The release ZIP contains Gwendolyn source code and its small local bridges. The setup scripts install third-party Python packages from their normal package indexes. Models, model servers and voice recordings are not bundled.

Core runtime dependencies:

- [Requests](https://github.com/psf/requests)
- [NumPy](https://github.com/numpy/numpy)
- [python-sounddevice](https://github.com/spatialaudio/python-sounddevice)
- [faster-whisper](https://github.com/SYSTRAN/faster-whisper)

Optional integrations:

- [Ollama](https://github.com/ollama/ollama)
- [llama.cpp](https://github.com/ggml-org/llama.cpp)
- [Kokoro](https://github.com/hexgrad/kokoro)
- [Chatterbox](https://github.com/resemble-ai/chatterbox)
- [Vector 1A](https://github.com/Nephet2/restim-vector-live)

Each project and each model has its own license and distribution terms. Review those terms before installing or redistributing it.
