# Gwendolyn Direct Voice v0.45 — Director Personalities

This release separates Director identity from voice. The selected Director now changes planning, pacing, narrative-beat weighting, initiative, memory interpretation and opening—not merely accent and descriptive prompt text.

## Deep profiles

- **Gwendolyn — The Conductor:** balanced, polished direction; meaningful contrast, callbacks and well-timed intervention.
- **Natasha — The Strategist:** compact, decisive and purposeful; controlled sequences, higher initiative and deliberate dwell after successful moves.
- **Sophie — The Enchantress:** intimate, associative and responsive; slower initiative, richer callbacks and gradual thematic development.
- **Vesper — The Temptress:** restrained psychological suspense; foreshadowing, deceptive calm, contrast and delayed resolution.

Each profile includes an explicit anti-caricature guard. Accent spelling, stock catchphrases and repetitive genre clichés are discouraged.

## Memory behavior

Shared memories remain available to all Directors, while personality-scoped memories are supplied only to their owner. Each Director is instructed to interpret memory differently: strategy, intimacy, foreshadowing or conducted continuity.

## Interface

Director Setup now displays the selected personality’s archetype and operating doctrine. Disabling “Apply voice-specific Director Profile” restores the shared tuning and removes the behavioral policy while retaining the selected voice.
